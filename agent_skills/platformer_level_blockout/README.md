# Platformer Level Blockout Skill

## Problem Statement
Prepare a reusable workflow for planning, blocking out, and validating Super Monkee (and other 2D platformer) levels so that references, constraints, and layout proofs can be ingested long before final art.

## Responsibilities
- Gather visual/audio references plus mechanic constraints from ingest manifests.
- Produce structured blockout guides (tile counts, cadence, encounter pacing) that level designers can iterate on.
- Track per-level readiness so CI knows when to trigger future automation (pathfinding probes, collectible audits, etc.).
- Keep Super Monkee artifacts compatible with the shared AI-E ingestion + skills framework.
