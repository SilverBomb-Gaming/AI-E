# Checklist
1. Review the ingest manifest for the target Super Monkee batch and note the level identifiers + goals.
2. Collect the required reference media and stash copies under the appropriate ingest/media subfolders.
3. Draft a paper or digital blockout, translating mechanic constraints into tile counts and encounter order.
4. Record the layout decisions inside a structured doc or JSON so CI can diff revisions later.
5. Flag follow-up automation needs (sprite import, enemy tuning, playtest probes) and register them in AI-E Orchestrator.
