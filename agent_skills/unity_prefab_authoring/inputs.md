# Inputs
- Source model asset path (GLB/FBX located under `Assets/...`).
- Optional animation asset path (merged clips, additive packs, or retarget sets).
- Desired prefab output path (e.g., `Assets/Prefabs/Enemies/Zombie_001.prefab`).
- Target manifest entry from `AI-E/ingest/manifests` describing tags, domain, and skill intent.
- Environment metadata (task id, CI workspace root, artifact directory).
